

## Über das Projekt

Dieses Repository dient als Praxisprojekt zur Vertiefung meiner Kenntnisse in **Spring Boot**. Als Grundlage habe ich das bestehende Backend meiner Webseite verwendet (vgl. https://github.com/juli-ro/gametogather), um einen direkten Technologietransfer von **.NET** zu Java/Spring zu vollziehen.

**Hauptfokus dieses Projekts:**
* **Effizienter Wissenstransfer:** Nutzung meiner fundierten .NET-Erfahrung, um die Konzepte von Spring Boot schneller zu adaptieren und Parallelen zwischen den Frameworks zu ziehen.
* **Architektur & Patterns:** Implementierung einer sauberen Schichtenarchitektur.
* **Qualitätssicherung:** Optimierung der Codebasis durch eine umfassende Testabdeckung.
* **Refactoring:** Weiterentwicklung des ursprünglichen Backends für eine bessere Wartbarkeit und Skalierbarkeit.
